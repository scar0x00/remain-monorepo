# Deck list & search

## Browsing decks

- The output of the DeckList will change as the user types on the bar
- Throttling will be applied to the search bar change event
- There has to be shared state between the search bar and the deck list

## Deck list

- It must show deck name (without the .json suffix)
- It must show the creation date
- It must show a button to download/export the deck and another one to start a study session for that deck
